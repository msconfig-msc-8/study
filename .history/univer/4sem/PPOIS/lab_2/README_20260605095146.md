# Лабораторная работа №2 — Учёт студенческих работ

**Дисциплина:** Проектирование и программное обеспечение информационных систем (ППОИС)  
**Вариант:** 14  
**Язык:** Python 3  
**GUI:** PyQt5  
**Формат данных:** XML  

---

## Описание задачи

Десктопное приложение для учёта выполнения лабораторных (программных) работ студентами. Каждая запись содержит информацию о студенте: ФИО, курс, группа, общее число работ, число выполненных работ, язык программирования. Число невыполненных работ вычисляется автоматически.

## Модель данных

| Поле | Тип | Описание |
|---|---|---|
| `name` | `str` | ФИО студента |
| `course` | `int` | Курс (1–5) |
| `group` | `str` | Группа |
| `total_works` | `int` | Общее число работ |
| `done_works` | `int` | Число выполненных работ |
| `language` | `str` | Язык программирования |
| `not_done_works` | `int` | Вычисляемое: `total_works - done_works` |

Поле `not_done_works` — только вычисляемое свойство (`@property`), в XML не сохраняется.

### `Student` — [models/student.py](models/student.py)

Класс данных (`@dataclass`). Описывает одну запись о студенте.

| Элемент | Тип | Описание |
|---|---|---|
| `name` | `str` | ФИО студента |
| `course` | `int` | Курс |
| `group` | `str` | Группа |
| `total_works` | `int` | Общее число работ |
| `done_works` | `int` | Выполнено работ |
| `language` | `str` | Язык программирования |
| `not_done_works` | `@property` | `total_works - done_works`, только для чтения |
| `to_dict()` | метод | Преобразует объект в словарь (без `not_done_works`) |
| `from_dict(data)` | статический метод | Создаёт `Student` из словаря |

---

### `StudentService` — [services/student_service.py](services/student_service.py)

Слой бизнес-логики. Хранит список студентов в памяти и управляет XML-файлом.

**Атрибуты:**

- `_students: List[Student]` — список всех студентов в памяти
- `_filepath: str` — путь к последнему открытому/сохранённому файлу

**Методы:**

| Метод | Описание |
|---|---|
| `load(filepath)` | Читает XML через SAX-парсер, заполняет `_students` |
| `save(filepath?)` | Записывает `_students` в XML через DOM (pretty-print) |
| `get_all()` | Возвращает копию списка студентов |
| `add(student)` | Добавляет запись в конец списка |
| `update(index, student)` | Заменяет запись по индексу |
| `delete(index)` | Удаляет запись по индексу |
| `delete_many(students)` | Удаляет несколько записей по ссылкам на объекты |
| `search(key, value)` | Поиск по любому полю (строки — частичный, нечувствительный к регистру) |
| `unique_values(key)` | Возвращает отсортированный список уникальных значений поля |

**Вспомогательный внутренний класс `_StudentSAXHandler`** — реализует `ContentHandler` для SAX-парсинга. Накапливает данные тегов и создаёт объекты `Student` при закрытии тега `<student>`.

---

### `MainWindow` — [ui/main_window.py](ui/main_window.py)

Главное окно приложения (`QMainWindow`). Связывает UI с `StudentService`.

- Строит меню **Файл** и **Правка** с горячими клавишами
- Строит панель инструментов с кнопками быстрого доступа
- Содержит `QTableWidget` для отображения записей
- Содержит `PaginationWidget` для навигации по страницам
- При любом изменении данных вызывает `_reload()`, который пересчитывает пагинацию и перерисовывает таблицу

---

### `StudentDialog` — [ui/student_dialog.py](ui/student_dialog.py)

Диалог (`QDialog`) для ввода и редактирования одной записи.

- Используется и для добавления (передаётся `student=None`), и для редактирования (передаётся существующий `Student`)
- Поля: `QLineEdit` для ФИО, группы, языка; `QSpinBox` для курса (1–6), числа работ
- При нажатии «OK» выполняет валидацию: ФИО не пустое, `done_works ≤ total_works`
- Возвращает заполненный объект `Student` через метод `get_student()`

---

### `SearchDialog` — [ui/search_dialog.py](ui/search_dialog.py)

Диалог поиска записей (`QDialog`).

- Содержит виджет `_CriteriaWidget` для выбора критерия
- После нажатия «Найти» вызывает `StudentService.search()` и выводит результаты в отдельную таблицу с пагинацией
- Показывает счётчик найденных записей

---

### `DeleteByCriteriaDialog` — [ui/search_dialog.py](ui/search_dialog.py)

Диалог удаления по критерию (`QDialog`).

- Так же использует `_CriteriaWidget`, но без таблицы результатов
- Возвращает выбранный критерий через `get_filter()` → `(key, value)`
- Само удаление выполняет `MainWindow` после подтверждения пользователя

---

### `_CriteriaWidget` — [ui/search_dialog.py](ui/search_dialog.py)

Общий виджет (`QGroupBox`) с панелью критериев поиска. Переключение между критериями — через `QRadioButton`. Строковые поля используют `QLineEdit`, числовые и перечислимые — `QComboBox` с уникальными значениями из текущих данных.

Метод `get_filter()` возвращает пару `(key, value)`, совместимую с `StudentService.search()`.

---

### `PaginationWidget` — [ui/pagination_widget.py](ui/pagination_widget.py)

Виджет пагинации (`QWidget`). Генерирует сигнал `page_changed(page, per_page)` при смене страницы или размера страницы.

| Элемент | Описание |
|---|---|
| Кнопки `\|<` `<` `>` `>\|` | Переход на первую/предыдущую/следующую/последнюю страницу |
| `QComboBox` «На странице» | Выбор числа записей на странице: 5 / 10 / 20 / 50 |
| `set_total(n)` | Устанавливает общее число записей, пересчитывает страницы |
| `slice_data(data)` | Возвращает срез списка для текущей страницы |

## Функциональность

### Работа с файлами
- **Открыть (Ctrl+O)** — загрузить список студентов из XML-файла
- **Сохранить (Ctrl+S)** — сохранить в текущий файл
- **Сохранить как (Ctrl+Shift+S)** — сохранить в новый XML-файл

### Управление записями
- **Добавить (Ctrl+N)** — открывает диалог ввода нового студента
- **Редактировать (Ctrl+E)** — изменить выбранную строку
- **Удалить (Delete)** — удалить выбранную строку с подтверждением

### Поиск и фильтрация
- **Поиск (Ctrl+F)** — поиск студентов по любому полю (имя, группа, курс, язык, число работ). Поиск по строкам — нечувствителен к регистру, поддерживает частичное совпадение
- **Удаление по критерию (Ctrl+D)** — найти и массово удалить записи по выбранному критерию

### Интерфейс
- Таблица с сортировкой и выбором строк
- Пагинация (настраиваемое количество записей на страницу)
- Стилизованный интерфейс (тема Fusion + кастомный QSS)

## Работа с XML

Для **чтения** используется SAX-парсер (`xml.sax`) — потоковая обработка, эффективная для больших файлов.  
Для **записи** используется DOM (`xml.dom.minidom`) — форматированный XML с отступами.

Пример XML-файла:
```xml
<?xml version="1.0" encoding="utf-8"?>
<students>
  <student>
    <name>Иванов И.И.</name>
    <course>2</course>
    <group>ПО-21</group>
    <total_works>10</total_works>
    <done_works>7</done_works>
    <language>Python</language>
  </student>
</students>
```

## Тесты

Тесты расположены в папке `tests/` и используют `pytest`.

| Файл | Что тестируется |
|---|---|
| `test_student.py` | Модель `Student`: поля, `not_done_works`, `to_dict`, `from_dict` |
| `test_student_service.py` | CRUD, сохранение/загрузка XML, поиск, уникальные значения |

Покрытые сценарии:
- CRUD: добавление, обновление, удаление одной и нескольких записей
- XML round-trip: сохранение и повторная загрузка сохраняет все поля без потерь
- Сохранение без указанного пути выбрасывает `ValueError`
- Поиск по имени (точный, частичный, без учёта регистра)
- Поиск по группе, курсу, языку, числу работ, числу невыполненных работ
- Уникальные значения полей
